# 🎮 Memory Game

Игра «Найди пару» (Memory) на Python с использованием Tkinter.

## 📖 Описание

Классическая игра на память: открывайте по две карточки за ход, ищите совпадающие пары. Цель — найти все пары за минимальное количество ходов.

### Особенности

- ✅ **5 размеров поля**: от 4×4 до 12×12
- ✅ **100 уникальных эмодзи** (животные, природа)
- ✅ **Автоматическое масштабирование** карточек под размер окна
- ✅ **Счётчик ходов** и отслеживание прогресса
- ✅ **Плавная анимация** переворота карточек
- ✅ **Прокрутка** для больших полей
- ✅ **Окно победы** с результатом

## 🚀 Установка

### 1. Создайте виртуальное окружение (если ещё не создано)

```bash
python3 -m venv venv
```

### 2. Активируйте окружение

**Linux/macOS:**
```bash
source venv/bin/activate
```

**Windows:**
```bash
venv\Scripts\activate
```

### 3. Установите зависимости

```bash
pip install -r requirements.txt
```

> **Примечание:** Игра использует только встроенную библиотеку `tkinter`, которая входит в стандартную поставку Python.

### 4. Установите tkinter (если не установлен)

**Ubuntu/Debian:**
```bash
sudo apt-get install python3-tk
```

**Fedora:**
```bash
sudo dnf install python3-tkinter
```

**macOS:**
```bash
brew install python-tk
```

**Windows:**
Tkinter уже установлен вместе с Python.

## 🎮 Как играть

### Запуск

```bash
python main.py
```

### Правила

1. **На поле расположены карточки** рубашкой вверх
2. **Кликните по карточке**, чтобы перевернуть её
3. **Кликните по второй карточке** — если эмодзи совпали, пара остаётся открытой
4. **Если не совпали** — карточки перевернутся обратно через 0.8 секунды
5. **Найдите все пары** за минимальное количество ходов

### Управление

| Элемент | Описание |
|---------|----------|
| **Выпадающий список** | Выбор размера поля (4×4, 6×6, 8×8, 10×10, 12×12) |
| **🔄 Новая игра** | Кнопка запуска новой игры с выбранным размером |
| **Ходы** | Счётчик текущих попыток |
| **Пары** | Прогресс: найдено / всего |

### Советы

- 🧠 **Запоминайте расположение** открытых карточек
- 🎯 **Начните с малого**: поле 4×4 для разминки
- 🏆 **Хардкор**: попробуйте 12×12 (72 пары!)
- 🖱️ **Колёсико мыши**: прокрутка больших полей

## 🛠️ Настройка

### Изменение размеров поля

Откройте `memory_game/app.py` и измените словарь `GAME_SIZES`:

```python
GAME_SIZES = {
    "4×4": 4,
    "6×6": 6,
    "8×8": 8,
    "10×10": 10,
    "12×12": 12,
    "14×14": 14,  # Добавить новый размер
}
```

### Изменение эмодзи

Откройте `memory_game/game.py` и отредактируйте список `EMOJIS`:

```python
EMOJIS = [
    "🐶", "🐱", "🐭", ...  # Ваши эмодзи
]
```

## 📸 Скриншоты

Игра автоматически подстраивается под размер окна:
- Маленькое окно → карточки уменьшаются
- Большое окно → карточки увеличиваются
- Если карточки не влезают → появляется прокрутка

## 🐛 Решение проблем

### Ошибка: `No module named 'tkinter'`

Установите tkinter (см. раздел **Установка** выше).

### Окно не открывается

Убедитесь, что у вас есть графический интерфейс (X11/Wayland на Linux).

### Карточки не масштабируются

Измените размер окна — карточки подстроятся автоматически через 0.2 секунды.
